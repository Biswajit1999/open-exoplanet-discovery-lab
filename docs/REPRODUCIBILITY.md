# Reproducibility

## Clean environment

Core numerical pipeline:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .[test]
pytest -q
python scripts/run_validation_suite.py
```

Archive tooling:

```bash
python -m pip install -e .[archives]
python scripts/build_public_snapshot.py --output outputs/public_snapshot
```

Full research environment:

```bash
python -m pip install -e .[full,test]
```

## Public archive snapshots

`scripts/build_public_snapshot.py` retrieves:
- NETS III VizieR catalogue J/AJ/170/264;
- NETS IV / HD 190360 VizieR catalogue J/AJ/171/286;
- NASA Exoplanet Archive census;
- NASA Atmospheric Spectroscopy spectrum-level metadata.

Every output is accompanied by a JSON manifest containing query, access time, product identifiers, local checksums and selection rules.

## ESO overlap census

```bash
python scripts/build_eso_overlap_census.py --output outputs/eso_overlap_census
```

The script:
1. queries public NIRPS products from ESO `ivoa.ObsCore`;
2. groups products into target/epoch summaries;
3. performs coordinate-cone HARPS lookups;
4. reports one-to-one overlap counts within 1 h, 6 h, 1 d, 3 d and 7 d;
5. writes a provenance manifest.

This census is metadata-level. Precision-RV analysis still requires product-level PROCSOFT verification and correct RV/CCF extraction.

## Determinism

Deterministic tests use fixed seeds. Stochastic science runs must write their random seed into the result configuration.

## Environment capture

For a citable release, store:
- Python version;
- `pip freeze` or equivalent lock file;
- Git commit;
- configuration hash;
- manifest hashes;
- platform information.

## Raw data

Large archive files are normally reacquired from the original archive. Git stores:
- acquisition scripts;
- manifests;
- checksums;
- compact derived tables where licensing permits;
- generated figures/tables.

Do not commit access tokens, private observations, or third-party files whose redistribution terms are unclear.

## Figures and tables

Publication figures are generated by Python scripts/package functions and have machine-readable source tables where practical. The web application is not the canonical computation layer.

## Continuous integration

Two CI layers are maintained:
- unit/scientific invariants;
- deterministic numerical validation.

A separate public-snapshot workflow tests current archive connectivity and uploads the resulting snapshot as an artifact. Because external archives can be temporarily unavailable, that workflow is intentionally not used as the sole software-integrity gate.
